================================================================
GUIDE CRÉATION IHM — CODESYS Visualization
AS/RS QUADRA 10 — MENARA PRÉFA
================================================================
Résolution cible : 1280 × 800 px
Format position : (Gauche, Haut, Droite, Bas) en pixels

ÉTAPES PRÉLIMINAIRES
────────────────────
1. Dans CODESYS, importer dans cet ordre :
   - 00_DUT_UDT_MOULE.st        → DUT
   - 20_GVL_HMI.st              → GVL (nom : "GVL_HMI")
   - 21_FC_MouleIDToStr.st      → Function
   - 22_FC_EtapeG3ToStr.st      → Function
   - 23_FB_HMI_Controller.st    → Function Block
   - 24_FB_FaultInjector.st     → Function Block

2. Modifier PRG_MAIN (voir section PRG_MAIN en bas de ce guide).

3. Créer 4 objets Visualization (clic droit sur l'application → Add Object → Visualization) :
   - VIS_PRINCIPALE
   - VIS_COMMANDES
   - VIS_ALARMES
   - VIS_MODES_DEGRADES

4. Dans chaque Visualization, aller dans Visualization Properties :
   - Taille : 1280 × 800
   - Background color : RGB(26, 26, 46)   → #1A1A2E (fond bleu nuit industriel)

5. Activer WebVisu : clic droit sur le Device → Add Object → WebVisu
   Port par défaut : 8080
   URL d'accès : http://localhost:8080/webvisu.htm

6. Activer TargetVisu si écran local : clic droit Device → Add Object → TargetVisu

MODIFICATION PRG_MAIN
================================================================
Ajouter dans la section VAR de PLC_PRG :

  instHMI  : FB_HMI_Controller;
  instFault: FB_FaultInjector;

Ajouter en début de PLC_PRG (AVANT les copies GVL_IO → GVL_SIG) :

  // ── IHM : mise à jour textes, boutons, injection défauts ──────
  instHMI();
  instFault(
      FaultID  := GVL_HMI.HMI_FAULT_SEL,
      Inject   := GVL_HMI.HMI_BTN_INJECT,
      ResetFlt := GVL_HMI.HMI_BTN_FAULT_RESET,
      Desc     => GVL_HMI.HMI_FAULT_DESC,
      Result   => GVL_HMI.HMI_FAULT_RESULT,
      FltActive=> GVL_HMI.HMI_FAULT_ACTIVE
  );

Après les copies GVL_IO → GVL_SIG existantes, ajouter :

  // ── Forcer OR zone libre : bouton physique OU bouton HMI ──────
  GVL_SIG.ZONE_CONFIRMEE := GVL_IO.ZONE_LIBRE_BTN OR GVL_HMI.HMI_BTN_ZONE_OK;

================================================================
CONSEILS CODESYS VISUALIZATION
================================================================

COULEUR DYNAMIQUE D'UN RECTANGLE :
  - Clic droit → Properties → Frame/Fill Color → Dynamic → Variable : GVL_HMI.HMI_COL_MODE
  - Le type DWORD est interprété comme couleur ARGB (Alpha=FF toujours)

LED (LAMP) :
  - Tool Box → Lamp → poser, double-clic → Properties
  - Variable : la variable BOOL à visualiser
  - Color Normal OFF : RGB(64,64,64) = #404040
  - Color Normal ON  : RGB(0,200,0) = #00C800
  - Shape : Ellipse (aspect LED industriel)

BAR DISPLAY (barre de progression) :
  - Tool Box → Bar Display → poser
  - Variable : GVL_HMI.HMI_G3_PCT (type REAL)
  - Min=0.0  Max=100.0
  - Direction : Left to Right

COMBO BOX (liste déroulante) :
  - Tool Box → Combo Box → poser
  - Variable : INT (ex : GVL_HMI.HMI_SEL_MOULE)
  - Text List : créer un objet Text List dans le projet
    → Add Object → Text List → nommer "TL_Moules"
    → Ajouter : 0="Choisir...", 1="MOULE_A", ..., 5="MOULE_E"

BOUTON AVEC ACTION ST :
  - Double-clic bouton → Properties → Input → Mouse Down
  - Action : Execute ST expression
  - Expression : GVL_HMI.HMI_BTN_CMD_CM := TRUE;

CLIGNOTEMENT VOYANT D'URGENCE :
  - Lamp → Properties → Toggle Visibility avec fréquence 500ms
  - Ou utiliser VisToggle avec variable booléenne et timer dans le code ST

TAILLE MINIMALE RECOMMANDÉE :
  - Textes lisibles en démo : police 12pt minimum
  - Boutons cliquables sur écran tactile : 120×45px minimum
